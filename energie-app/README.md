# Energie App

Energie App is een Home Assistant-app voor het monitoren van energieverbruik en -tarieven via een Next.js-webapp in een Docker-container.

## Functies

- Verbruiksoverzicht
- Contract- en tariefbeheer
- Facturenbeheer
- Home Assistant-synchronisatie
- Home Assistant API-integratie
- Docker-gebaseerde uitvoering in Home Assistant

## Gebruikte technologie

- Next.js
- React
- Prisma
- MariaDB/MySQL
- Docker
